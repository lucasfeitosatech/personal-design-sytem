# EmptyState

What a list shows when it has nothing: a quiet mark, a title, one line of body and one action.

**When to use.** Empty lists and failed loads. Never for zero results of a search with filters (say what to clear instead).

**Props.** `title` · `body` · `action` (one Button) · `tone` default·error.

**Platforms.** Same on both, full width on a phone.

**Notes.** New. The error tone explains what failed and offers the retry, never blames the person.

States drawn in the specimen card: default, hover (web) or pressed (device), focus, disabled, and where they apply loading, error, empty, selected and read-only. The state labels are the prop names.
