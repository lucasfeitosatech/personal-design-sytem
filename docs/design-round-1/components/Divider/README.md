# Divider

A 1px rule, horizontal or vertical.

**When to use.** Between list rows (inset, soft) and between inline metadata (vertical).

**Props.** `orientation` horizontal·vertical · `tone` default·soft · `inset`.

**Platforms.** Same on both.

**Notes.** New.

States drawn in the specimen card: default, hover (web) or pressed (device), focus, disabled, and where they apply loading, error, empty, selected and read-only. The state labels are the prop names.
