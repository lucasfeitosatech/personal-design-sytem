# Section

A titled block with an optional mono meta on the right, an optional quiet action and its content.

**When to use.** Grouping a page into months, categories or settings areas.

**Props.** `title` · `meta` (mono: a total, a count, a date) · `action` (Button ghost sm) · `as` h2·h3 · `children`.

**Platforms.** Same on both.

**Notes.** New.

States drawn in the specimen card: default, hover (web) or pressed (device), focus, disabled, and where they apply loading, error, empty, selected and read-only. The state labels are the prop names.
