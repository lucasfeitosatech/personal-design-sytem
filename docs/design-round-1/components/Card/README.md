# Card

A bordered surface in three tones; elevation is luminance and a 1px border, never a shadow.

**When to use.** Group related content. `flush` removes the padding so a list or table runs edge to edge (rows separated by an inset Divider).

**Props.** `tone` default·raised·muted · `flush`.

**Platforms.** Same on both.

**Notes.** Shipping.

States drawn in the specimen card: default, hover (web) or pressed (device), focus, disabled, and where they apply loading, error, empty, selected and read-only. The state labels are the prop names.
